## Codebase Patterns
- Token emission account resolution is shared via `resolveTokenEmissionAccounts()` in `use-staking.ts`
- Unstake functions (pNFT, Core, Nifty) all use the same pattern for resolving emission accounts
- Use `getTokenAuthorityPda()` for deriving token authority, `getAssociatedTokenAddressSync()` for vault/reward accounts
- Emission addresses extraction is shared via `getEmissionAddresses(collection)` in `stores/stake.ts`
- Use `logger.debug()` for debug logs (suppressed in production), `logger.warn()` for warnings, `logger.error()` for errors
- Logger is in `lib/logger.ts` and respects `import.meta.env.DEV`
