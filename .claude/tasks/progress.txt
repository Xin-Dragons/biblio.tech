## Codebase Patterns - IMPORTANT EXISTING CODE

**CRITICAL: @solana/kit ONLY**
- NEVER use @solana/web3.js
- Use @solana/kit for all RPC, transactions, subscriptions
- Kinobi-generated clients for Core, pNFT, Nifty

**EXISTING PATTERNS:**
- Wallet adapter: @solana/connector/react (useWallet hook)
- Transaction signing: see apps/web/src/lib/transaction.ts
- Toast notifications: use existing toast system (sonner)
- Dialog pattern: apps/web/src/components/ui/dialog.tsx
- Form inputs: apps/web/src/components/ui/input.tsx, textarea.tsx

**SIDEBAR (apps/web/src/components/layout/sidebar.tsx):**
- NavItem component for navigation links
- Sections with headers (e.g., "Wallet", "Tags")
- Icons from lucide-react

**ROUTING (apps/web/src/App.tsx):**
- React Router v7
- Layout component wraps authenticated routes
- Add new routes inside Layout

**ASSET STANDARDS:**
- Core Assets: @metaplex-foundation/mpl-core (or Kinobi client)
- pNFTs: @metaplex-foundation/mpl-token-metadata (or Kinobi client)
- Nifty: @nifty-oss/asset (or Kinobi client)

**FILE UPLOAD (apps/web/src/lib/irys.ts):**
- Use Irys for Arweave uploads via @irys/web-upload and @irys/web-upload-solana
- uploadToIrys(file, address, signer) - uploads File, returns { uri, arweaveUri, id }
- uploadJsonMetadata(metadata, address, signer) - uploads NFT metadata JSON
- Requires wallet address (string) and signer from useTransactionSigner()
- Gateway: https://gateway.irys.xyz/{id} (also available at https://arweave.net/{id})
