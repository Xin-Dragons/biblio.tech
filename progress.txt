## Codebase Patterns
- The monorepo uses pnpm workspaces with apps/ and packages/ directories
- IDL files go in packages/solana-programs/idls/
- The stake IDL was migrated from apps/legacy/src/apps/stake/idl/stake.json
- Generated SDK may have export conflicts when program name matches instruction name (e.g., stake program has stake instruction). Fix by aliasing conflicting types in index.ts and programs/stake.ts
- Run `pnpm install` from root before running scripts in packages
- Run `pnpm generate` in packages/solana-programs to regenerate SDK from IDLs
- **@solana/kit version mismatch**: API uses v5.x, solana-programs uses v2.x. Use manual RPC calls + decoders instead of SDK fetch functions
- Add workspace dependencies with: `pnpm --filter @biblio/api add "@biblio/solana-programs@workspace:*"`
- Service pattern: Follow apps/api/src/services/das.ts pattern - create getClient(env) helper, export typed functions
- Route pattern: Create Hono router in apps/api/src/routes/{name}.ts, export as `{name}Routes`, register in index.ts with `app.route("/path", routes)`
- **getProgramAccounts memcmp filters in @solana/kit v5**: Requires branded types for bytes field. Create local type: `type Base58EncodedBytes = string & { readonly "__brand:@solana/kit": "Base58EncodedBytes"; readonly "__stringEncoding:@solana/kit": "base58" }` and cast base58 strings to it
- StakeRecord memory layout: discriminator (8 bytes, offset 0), staker (32 bytes, offset 8), owner (32 bytes, offset 40)
- **Stake program PDA seeds**: STAKE_RECORD/NFT_RECORD/COLLECTION + staker_pubkey + mint_pubkey (uppercase seed prefixes)
- **Additional PDAs**: PROGRAM_CONFIG (global singleton), nft_authority + staker (lowercase for nft authority)
- **Codama to web3.js conversion**: Use codamaInstructionToWeb3() helper. Role values: 0=readonly, 1=writable, 2=readonly signer, 3=writable signer
- **FEES_WALLET**: FCp3p6jRvtbng7NQpUYiNx39wyvJ2LZjuhE1bPt37EVE
- **MPL_CORE_PROGRAM_ID**: CoREENxT6tW1HoK8ypY1SxRMZTcVPm7R94rH4PZNhX7d
- **TOKEN_AUTHORITY PDA**: ["token_authority", emission_pubkey] - controls stake token vault for reward distribution
